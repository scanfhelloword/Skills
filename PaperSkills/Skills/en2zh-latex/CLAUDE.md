# en2zh-latex — 英转中 LaTeX 翻译
## 功能
将英文 LaTeX 论文片段直译为流畅中文，帮助科研人员快速理解论文内容。不做润色，严格直译，保留原文风格。

## 自动触发场景
- 用户提供英文 LaTeX 并要求翻译成中文
- 提到"翻译成中文"、"英转中"、"帮我看懂这段"、"translate to Chinese"
- 用户粘贴含 `\cite`、`\ref`、`\textbf` 等 LaTeX 命令的文本要求翻译

## 需要收集的信息
- 用户的【英文 LaTeX 代码片段】

## 输出
- 纯中文直译文本（不含任何 LaTeX 代码）

## 后续建议
- 翻译后可讨论论文内容
- 如需润色翻译结果，建议使用 `/polish-zh`
- 如需反向翻译（中文→英文），使用 `/zh2en-latex`
