# zh2en-latex — 中转英 LaTeX 翻译

将中文草稿翻译并润色为英文 LaTeX 学术论文片段。

## 调用

- **手动**：输入 `/zh2en-latex`，然后提供中文草稿
- **自动**：当你说"帮我把这段翻译成英文用于论文"时自动触发

## 输入

中文草稿（学术论文内容）。

## 输出

- **Part 1 [LaTeX]**：翻译润色后的全英文 LaTeX 代码，特殊字符已转义
- **Part 2 [Translation]**：中文直译，用于核对逻辑是否符合原意

## 相关 Skills

- `/polish-en` — 对翻译结果进行深度润色
- `/zh2en-word` — 如果需要 Word 格式而非 LaTeX
- `/logic-check` — 检查翻译后的逻辑一致性
- `/deai-en` — 去除翻译中的 AI 味
