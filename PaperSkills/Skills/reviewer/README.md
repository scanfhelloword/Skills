# reviewer — Reviewer 视角审视论文

模拟顶会审稿人对论文进行全评估，输出审稿报告和改稿策略。

## 调用
- **手动**: `/reviewer`
- **自动**: 上传 PDF 说"帮我审稿"

## 输入
- PDF 论文文件
- 投稿目标（如 ICML 2026）

## 输出
- Part 1: 审稿报告（Summary/Strengths/Weaknesses/Rating）
- Part 2: 战略改稿建议（问题根源/可救性判断/行动指南）
